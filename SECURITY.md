# Security policy

Please do not report security vulnerabilities through a public Issue or Discussion.

Email [support@promptpilot-tab.com](mailto:support@promptpilot-tab.com) with:

- A concise description of the issue
- Reproduction steps
- The affected browser, extension version, and website
- The expected security impact

Do not include real API Keys, passwords, session tokens, or another person's data. We will acknowledge the report and follow up through email.
