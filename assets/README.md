## Publishing rules

- Use only approved website, store, or promotional-video sources.
- Remove account information, personal email addresses, API Keys, and staging-only URLs.
- Show real product behavior; do not invent numbers, testimonials, or compatibility claims.
- Keep important text legible at GitHub's content width.
- Link to hosted video instead of committing the source video file.
