# Contributing

Thank you for helping improve PromptPilot Tab.

## What we welcome

- Reproducible bug reports
- Feature requests with a clear user scenario
- Questions and workflow examples in GitHub Discussions（GitHub 讨论区）
- Responsible security reports sent privately

## Closed-source product

PromptPilot Tab is proprietary software and its source code is maintained in a private repository. This public repository is for product information, public updates, and community feedback, so source-code pull requests are not accepted.

Before opening an Issue, remove prompts, account details, API Keys, email addresses, and other private information from screenshots and logs.
